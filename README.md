# software-company

A simple one-page website for a software development company, built with HTML and CSS as a Git & GitHub collaboration exercise.

## Team

- **Mahmoud Mohamad** (Student A, repository owner): header, hero section
- **Mohammad Kassem** (Student B, collaborator): services section, footer

## Website sections

- **Header**: company name and navigation
- **Hero**: main heading, description, and call-to-action
- **Services**: Web Development, Mobile Apps, Cloud Solutions
- **Footer**: contact information and copyright

## How to run

1. Clone the repository:
   ```
   git clone https://github.com/Mahmoud1websites/software-company.git
   ```
2. Open `index.html` in any web browser.

## Git workflow

- `main`: final, stable version
- `dev`: shared development branch
- `feature/*`: one branch per feature, created from `dev`

Every change goes: **feature branch → Pull Request → code review → `dev` → `main`**.
